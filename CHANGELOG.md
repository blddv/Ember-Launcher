# Изменения EMBER Launcher

## 2.2.5B — 27.11.2026

### Исправлено

- Пустое тёмно-синее окно: локальные объявления сценариев интерфейса изолированы друг от друга. Повторные `const EMB` / `const t` больше не конфликтуют при загрузке через обычные `<script>`.
- Названия языков присваиваются при создании объекта переводчика, а не до его инициализации.
- Начальная отрисовка больше не ждёт сетевой загрузки манифеста Mojang и текущего скина. Ошибка манифеста показывается уведомлением, а не блокирует окно.
- До запуска интерфейса виден статический экран с кнопками повторного запуска и закрытия. Ошибки сценариев и начального IPC отображаются текстом.
- Для Rust-движков различаются недоступный репозиторий (404), лимит GitHub, отсутствие опубликованных релизов и отсутствие готового файла под систему. Пустой список больше не приводит к обращению к `.tag` у `null`.
- Запуск Horizon с явно закреплённой версией больше не делает ненужный запрос последнего релиза; установленный движок можно получить из локального кеша.
- На странице Rust отключена кнопка скачивания, если доступный релиз не найден.

### Документация и проверки

- Дополнен список возможностей: несколько аккаунтов, скины, обложки, операции со сборками и резервное копирование миров, менеджер модов, обновления, диагностика падений, языки и настройки запуска.
- Примеры имён установщиков приведены к версии `package.json` — 2.2.5A.
- Добавлены автоматические проверки загрузки сценариев в общем браузерном контексте, отрисовки и навигации, сетевых отказов и ответов GitHub для Rust-движков.

### Известное внешнее ограничение

На 27.11.2026 GitHub API отвечает `404` на запросы к `horizon-rust/horizon` и `horizon-rust/horizon-mods`. Скачать официальный движок или реестр по настроенным адресам сейчас невозможно. Эти изменения исправляют ошибки лаунчера и диагностику, но **не подтверждают работоспособность Horizon** и не восстанавливают чужие репозитории. Автоматической замены на сторонний форк нет.

## Возможности, уже присутствовавшие в 2.2.5A

Этот раздел фиксирует функции, найденные в исходниках, а не приписывает их текущей правке. История их появления по отдельным релизам не восстанавливалась.

- Microsoft, Ely.by и оффлайн-профили; несколько аккаунтов и защищённое хранение токенов.
- Каталоги скинов Ely.by / Mojang / LittleSkin, поиск по нику, текущий скин и загрузка скина Microsoft через API; переход на сайт для Ely.by.
- Vanilla / Fabric / Quilt / Forge / NeoForge и раздельные папки сборок; выбор версии загрузчика.
- Поиск, дублирование, импорт/экспорт ZIP, обложки сборок и архивы миров.
- Источники Modrinth, CurseForge, Hangar, Smithed, GitHub и установка по ссылке; фильтры, пагинация, статусы установленных модов, обновление модов Modrinth.
- Менеджер модов: просмотр, переключение и удаление файлов.
- Интеграции Horizon / Rustcraft с отдельными сборками; реестр модов Horizon с проверками файлов (зависят от доступности внешних проектов).
- Orange Visuals, пресеты производительности, пакет оптимизаторов, Iris и встроенные шейдерпаки.
- Палитра Ctrl+K, скриншоты, перенос папки данных, учёт времени игры.
- Проверка и загрузка обновлений лаунчера, подбор установщика для ОС, проверка опубликованных SHA-256; автоматическая установка на Windows и для Linux AppImage, открытие установщика на остальных платформах.
- Окно диагностики падений с отчётом, логом и рекомендациями.
- 15 языков, отключение анимаций, облегчённый интерфейс, настройки памяти/JVM/разрешения игры и сворачивание в трей при работающей игре.
