# EMBER Launcher

Лаунчер Minecraft в фирменных цветах: **#050B1A** (тёмно-синий) и **#FF7100** (оранжевый).

## Что умеет

- **Аккаунты**: Ely.by (логин/пароль, поддержка 2FA через `пароль:код`) и оффлайн-режим.
- **Загрузчики**: Vanilla, Fabric, Quilt, Forge и NeoForge. Для каждой сборки можно выбрать версию загрузчика.
- **Minecraft на Rust**: отдельные движки Horizon и Rustcraft — это не загрузчики, а самостоятельные клиенты Minecraft Java Edition 26.3, переписанные на Rust. У них своя вкладка, свои сборки, своя папка игры и свои моды.
- **Версии Minecraft**: любая версия из манифеста Mojang (релизы и снапшоты). Для Vanilla моды не показываются и не ставятся: сначала создайте сборку с загрузчиком.
- **Сборки**: отдельная папка на каждую сборку (моды, миры, настройки).
- **Моды и сборки**:
  - **Modrinth**: моды (с обязательными зависимостями), сборки `.mrpack`, ресурспаки.
  - **CurseForge**: моды, сборки (`manifest.json`), ресурспаки. Нужен бесплатный API-ключ.
  - **Hangar**: плагины Paper. Файл сохраняется в `server-plugins` для серверов.
  - **Smithed**: датапаки и ресурспаки.
  - **GitHub**: Fabric `.jar` из последнего релиза репозитория. Необязательный токен поднимает лимит запросов.
  - **По ссылке**: прямая ссылка на `.jar`, `.zip` (ресурспак) или `.mrpack` с любого сайта.
  - **Horizon (Rust)**: официальный реестр модов для Minecraft на Rust — `.hmod` и нативные `.hnmod`, сборки `.hpack` и ресурспаки. Каждый файл сверяется по размеру и SHA-256, снятые с публикации не ставятся. Шейдерпаки `.hshader` реестр пока не отдаёт: они кладутся в `shaderpacks` сборки вручную и выбираются в игре.
  - **Rust: GitHub**: `.hmod` из последнего релиза репозитория, которого ещё нет в реестре. Файлы не проверены.
  - Источники не смешиваются: сборка Java Edition видит только Modrinth, CurseForge, Hangar, Smithed и GitHub, а сборка Horizon — только реестр Horizon и Rust-раздел GitHub. `.jar` в Horizon не работает, `.hmod` — в Java-сборке.
- **Уже установленные моды**: в поиске они зачёркиваются и не ставятся повторно. Проверка идёт по файлам в папке `mods`, поэтому удалённый мод можно скачать снова. Если на Modrinth вышла новая версия, вместо «Уже установлено» появляется кнопка «Обновить».
- **Бесконечная прокрутка**: результаты Modrinth, CurseForge, Hangar и GitHub подгружаются при прокрутке. Smithed отдаёт одну страницу.
- **Фильтр по загрузчику**: поиск модов и установка идут под загрузчик выбранной сборки, Fabric-моды не предлагаются сборкам Forge или NeoForge.
- **Палитра команд (Ctrl+K)**: быстрый переход по разделам, сборкам и действиям.
- **Плеер музыки**: панель внизу, своя папка с треками (MP3, OGG, WAV, FLAC, M4A, AAC, Opus), громкость, повтор и перемешивание.
- **Скриншоты**: просмотр снимков всех сборок.
- **Папка данных**: в Настройках можно выбрать любую папку. Данные переносятся, лаунчер перезапускается, можно вернуть стандартную папку.
- **Orange Visuals 1.6.0**: собственный мод. Режим для слабых ПК (меньше обновлений HUD и миникарты, без виньетки), HUD (FPS, координаты, время), миникарта с поворотом по взгляду, полная карта на **N**, метки на **B**, плавный зум на **C**, своя точка-прицел, баннер «Сейчас играет» сверху экрана, если включена музыка лаунчера. Меню мода открывается коротким нажатием **R Shift** (клавишу можно сменить в Настройках). Включается и выключается в Настройках. При выключении мод удаляется из сборок. Fabric API ставится автоматически из Modrinth.
- **Java**: если путь не задан, лаунчер сам скачивает нужную Java (Adoptium).

## Minecraft на Rust

В лаунчере это отдельная платформа, а не загрузчик. Вкладка **«Minecraft Rust»** — про движки, вкладка **«Моды и сборки»** — про их моды.

| Движок | Что это | Моды |
| --- | --- | --- |
| **Horizon** (`horizon-rust/horizon`) | Minecraft Java Edition 26.3, переписанный на Rust: свой рендер, свои миры, читает ванильные сохранения | свой реестр `.hmod` (WebAssembly-моды в песочнице) |
| **Rustcraft** (`neotoxicfr/rustcraft`) | клиент 26.3 на Rust, который запускается **вместо** `java.exe` | нет |

Как это работает:

1. **Создание сборки**: «Сборки» → «Новая сборка» → платформа `Horizon (Rust)` или `Rustcraft (Rust)`. Версию движка можно выбрать вручную, «Авто» — последний релиз с GitHub. Версия Minecraft у этих сборок фиксированная — 26.3.
2. **Движок** скачивается из релизов GitHub в `runtime/rust/<платформа>/<версия>` и проверяется по `SHA256SUMS` (Horizon) или по файлу `.sha256` (Rustcraft).
3. **Данные игры**. Horizon не содержит файлов Minecraft: он готовит их из вашей копии 26.3 (клиент, библиотеки, ресурсы и `server.jar`). Лаунчер скачивает всё сам в свою папку данных и запускает `horizon-prepare`; Java 25 для этого тоже скачивается автоматически. Подготовка идёт один раз, занимает несколько минут и требует около 4 ГБ свободной ОЗУ.
4. **Файлы версии**. Если `26.3.json` был сохранён старой версией лаунчера в пересобранном виде, лаунчер приводит его к оригиналу Mojang: Horizon сверяет SHA-1 и иначе откажется готовить данные.
5. **Запуск**. Horizon стартует со своей папкой игры (`HORIZON_HOME` = папка сборки), ресурсы передаются через `--resources`. Rustcraft запускается как замена Java: лаунчер передаёт ему обычные аргументы игры (`--gameDir`, `--username`, `--version`).
6. **Моды**. Всё ставится в папку сборки: моды — `horizon-mods/<id>.hmod` (включаются строкой `mod.<id>:true` в `horizon-mods.txt`), ресурспаки — `resourcepacks/`, шейдерпаки — `shaderpacks/` (вручную). Включение и выключение модов — в окне «Моды» на карточке сборки; там же видно, что установлено из реестра.

Аккаунт Ely.by для Rust-сборок не нужен. Ник задаётся в «Настройках» («Ник в Minecraft на Rust»). Скриншоты, миры, настройки и краш-отчёты лежат в папке своей сборки.

Если движок упал, открывается то же окно разбора, что и для Java, но без упоминаний Java: заголовок называет движок, а типичные причины он узнаёт по тексту отчёта — не подготовлены данные игры, не хватает системной библиотеки, не подошёл видеодрайвер, не хватило памяти, паника самого движка. Отчёт Horizon лежит в `<папка сборки>/crash-reports`, лог — в `<папка сборки>/logs/latest.log`.

У сборки **Rustcraft** поиск модов заменён объяснением: модов у него нет, вместо списка — кнопка «Создать сборку Horizon». Ресурспаки `.zip` в такую сборку ставить можно через «По ссылке».

## Запуск из исходников

```bash
npm install
npm start
```

## Сборка Windows exe

```bash
npm run dist
```

Результат появляется в `dist/`: установщик `EMBER Launcher Setup 2.1.3.exe`. Портативная сборка отключена, чтобы файл был компактным.

Сборка на Linux требует Wine (с 32-битной частью) для редактирования ресурсов exe.

## Структура

```
main.js              процесс Electron, IPC
preload.js           безопасный мост к интерфейсу
src/
  minecraft.js       манифест, библиотеки, ресурсы, Fabric, аргументы запуска
  java.js            поиск и скачивание Java
  auth.js            Ely.by и оффлайн
  providers.js       Modrinth / CurseForge / Hangar и установка
  mods.js            синхронизация мода Orange Visuals
  instances.js       сборки (Java Edition и Minecraft на Rust)
  rust.js            движки Horizon и Rustcraft: релизы, загрузка, подготовка, запуск
  horizon.js         реестр модов Horizon: поиск, установка, horizon-mods.txt
  store.js           настройки (launcher.json)
renderer/            интерфейс (HTML/CSS/JS)
mods/                готовый jar мода Orange Visuals
mods-src/            исходники мода (Fabric 1.21.1, Java 21)
```

## Ограничения

- Мод Orange Visuals собран только под **Minecraft 1.21.1 (Fabric)**. Для других версий нужна отдельная сборка с нужными версиями Yarn и Fabric API, а для Forge и NeoForge — отдельный вариант мода.
- Forge и NeoForge 1.21.1 проверены запуском (headless). Другие версии Forge/NeoForge не проверялись. NeoForge 1.20.1 пока не поддерживается.
- Quilt запускается, но Orange Visuals для него не ставится.
- Вход в Ely.by и CurseForge не проверен на реальных аккаунтах и ключе (нужны ваши данные).
- Некоторые авторы на CurseForge запрещают скачивание через API. Такие файлы придётся скачать вручную.
- Technic требует приватный ключ, SpigotMC и Planet Minecraft не дают публичного API. Поэтому их нет в списке, а для любого другого сайта используется «По ссылке».
- GitHub-поиск ищет по всем репозиториям, поэтому качество результатов ниже, чем у Modrinth.
- **Horizon**: данные игры готовятся из вашей копии Minecraft Java Edition 26.3 — без неё движок не запустится. Реестр модов Horizon сейчас содержит только моды (разделы «Сборки», «Ресурспаки» и «Шейдеры» могут быть пустыми — они появятся, когда реестр их опубликует). Ресурспаки и шейдерпаки включаются в самой игре.
- **Rustcraft**: клиент в разработке (v0.0.1), модов не поддерживает, и для него тоже нужна версия 26.3. Запускается как замена `java.exe` — лаунчер передаёт ему аргументы обычной игры.
- **Linux**: Horizon и Rustcraft требуют системные библиотеки (`libasound2`, `libudev1`, `libxkbcommon0`). Если их нет, окно падения подскажет, что доустановить.
- Проверка подготовки Horizon на машине с 2 ГБ ОЗУ упирается в память генератора данных (нужно ~4 ГБ). На обычном ПК подготовка проходит целиком.
