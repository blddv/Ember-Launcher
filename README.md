# EMBER Launcher

Лаунчер Minecraft в фирменных цветах: **#050B1A** (тёмно-синий) и **#FF7100** (оранжевый).

## Что умеет

- **Аккаунты**: Ely.by (логин/пароль, поддержка 2FA через `пароль:код`) и оффлайн-режим.
- **Загрузчики**: Vanilla, Fabric, Quilt, Forge и NeoForge. Для каждой сборки можно выбрать версию загрузчика.
- **Версии Minecraft**: любая версия из манифеста Mojang (релизы и снапшоты). Для Vanilla моды не показываются и не ставятся: сначала создайте сборку с загрузчиком.
- **Сборки**: отдельная папка на каждую сборку (моды, миры, настройки).
- **Моды и сборки**:
  - **Modrinth**: моды (с обязательными зависимостями), сборки `.mrpack`, ресурспаки.
  - **CurseForge**: моды, сборки (`manifest.json`), ресурспаки. Нужен бесплатный API-ключ.
  - **Hangar**: плагины Paper. Файл сохраняется в `server-plugins` для серверов.
  - **Smithed**: датапаки и ресурспаки.
  - **GitHub**: Fabric `.jar` из последнего релиза репозитория. Необязательный токен поднимает лимит запросов.
  - **По ссылке**: прямая ссылка на `.jar`, `.zip` (ресурспак) или `.mrpack` с любого сайта.
  - **Сборка `.mrpack` с диска**: кнопка «Импорт сборки» в разделе «Сборки» или на вкладке «По ссылке».
    Файл можно просто перетащить в окно лаунчера. Архив разворачивается в новую сборку: версия Minecraft,
    загрузчик, моды и overrides берутся из `modrinth.index.json`. Файлы, которые Modrinth не отдаёт
    на скачивание, пропускаются и перечисляются в уведомлении — установка из-за них не падает.
- **Уже установленные моды**: в поиске они зачёркиваются и не ставятся повторно. Проверка идёт по файлам в папке `mods`, поэтому удалённый мод можно скачать снова. Если на Modrinth вышла новая версия, вместо «Уже установлено» появляется кнопка «Обновить».
- **Бесконечная прокрутка**: результаты Modrinth, CurseForge, Hangar и GitHub подгружаются при прокрутке. Smithed отдаёт одну страницу.
- **Фильтр по загрузчику**: поиск модов и установка идут под загрузчик выбранной сборки, Fabric-моды не предлагаются сборкам Forge или NeoForge.
- **Палитра команд (Ctrl+K)**: быстрый переход по разделам, сборкам и действиям.
- **Плеер музыки**: панель внизу, своя папка с треками (MP3, OGG, WAV, FLAC, M4A, AAC, Opus), громкость, повтор и перемешивание.
- **Скриншоты**: просмотр снимков всех сборок.
- **Папка данных**: в Настройках можно выбрать любую папку. Данные переносятся, лаунчер перезапускается, можно вернуть стандартную папку.
- **Orange Visuals 1.6.0**: собственный мод. Режим для слабых ПК (меньше обновлений HUD и миникарты, без виньетки), HUD (FPS, координаты, время), миникарта с поворотом по взгляду, полная карта на **N**, метки на **B**, плавный зум на **C**, своя точка-прицел, баннер «Сейчас играет» сверху экрана, если включена музыка лаунчера. Меню мода открывается коротким нажатием **R Shift** (клавишу можно сменить в Настройках). Включается и выключается в Настройках. При выключении мод удаляется из сборок. Fabric API ставится автоматически из Modrinth.
- **Java**: если путь не задан, лаунчер сам скачивает нужную Java (Adoptium).

## Запуск из исходников

```bash
npm install
npm start
```

## Сборка Windows exe

```bash
npm run dist
```

Результат появляется в `dist/`: установщик `EMBER Launcher Setup 2.0.7.exe`. Портативная сборка отключена, чтобы файл был компактным.

Сборка на Linux требует Wine (с 32-битной частью) для редактирования ресурсов exe.

## Структура

```
main.js              процесс Electron, IPC
preload.js           безопасный мост к интерфейсу
src/
  minecraft.js       манифест, библиотеки, ресурсы, Fabric, аргументы запуска
  java.js            поиск и скачивание Java
  auth.js            Ely.by и оффлайн
  providers.js       Modrinth / CurseForge / Hangar и установка
  mods.js            синхронизация мода Orange Visuals
  instances.js       сборки
  store.js           настройки (launcher.json)
renderer/            интерфейс (HTML/CSS/JS)
mods/                готовый jar мода Orange Visuals
mods-src/            исходники мода (Fabric 1.21.1, Java 21)
```

## Ограничения

- Мод Orange Visuals собран только под **Minecraft 1.21.1 (Fabric)**. Для других версий нужна отдельная сборка с нужными версиями Yarn и Fabric API, а для Forge и NeoForge — отдельный вариант мода.
- Forge и NeoForge 1.21.1 проверены запуском (headless). Другие версии Forge/NeoForge не проверялись. NeoForge 1.20.1 пока не поддерживается.
- Quilt запускается, но Orange Visuals для него не ставится.
- Вход в Ely.by и CurseForge не проверен на реальных аккаунтах и ключе (нужны ваши данные).
- Некоторые авторы на CurseForge запрещают скачивание через API. Такие файлы придётся скачать вручную.
- Technic требует приватный ключ, SpigotMC и Planet Minecraft не дают публичного API. Поэтому их нет в списке, а для любого другого сайта используется «По ссылке».
- GitHub-поиск ищет по всем репозиториям, поэтому качество результатов ниже, чем у Modrinth.
